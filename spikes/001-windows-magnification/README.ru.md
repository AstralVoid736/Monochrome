# Monochrome — диагностическая сборка для Windows 11

Это проба системного фильтра на **1,5 секунды**, не готовая версия Monochrome. Значка, горячей клавиши, автозапуска и 25-минутного режима в ней пока нет.

1. Распакуй весь ZIP. Нужна обычная интерактивная сессия Windows 11 и уже установленный **.NET Runtime 8** той же архитектуры, что и Windows (x64 или Arm64). В терминале `dotnet --list-runtimes` должен показать `Microsoft.NETCore.App 8.0.x`. Администратор для пробы не нужен; не запускай её с повышением прав.
2. В цветном режиме запусти `00-Check.cmd`. Это чтение: `READ ONLY: Identity` означает, что текущая матрица экранной лупы нейтральна. Если вывод другой, на этом остановись и сохрани текст.
3. Запусти `01-Test.cmd` и нажми `Y`. Смотри на видимый цветной объект на рабочем столе: он должен посереть на 1,5 секунды, затем вернуть цвета. Окно не закрывай. Зафиксируй отдельно, что было видно, и что напечатала программа. `PASS readback` означает, что API подтвердил запись и возврат матрицы; это не само наблюдение экрана.

Проба не пишет в реестр, ничего не устанавливает, не меняет параметры специальных возможностей и не отправляет данные. Если другая матрица уже активна или текущую не удалось прочитать, проба останавливается. `Ctrl+C` во время пробы запрашивает досрочное восстановление. Не переключай фильтры и экранную лупу во время теста: сравнение и запись не являются одной атомарной операцией.

Если экран остался серым **сразу после этой пробы**, не повторяй `01-Test.cmd`. Из этой же папки в терминале можно явно запросить восстановление: `dotnet .\Monochrome.WindowsProbe.dll --restore-probe-matrix`. Команда запишет нейтральную матрицу только если видит точную матрицу Monochrome, и проверит результат. Она не может доказать, какая программа выставила совпадающую матрицу, поэтому не запускай её для другого фильтра. Если восстановление не подтверждено, сохрани текст результата; прежде чем продолжать, при необходимости выйди из сеанса и войди снова.

Если `dotnet` не найден, проба ничего не сделала. DLL не имеет подписи Authenticode. Для проверки ZIP используй `SHA256SUMS.txt` из того же релиза; не выключай защиту Windows. Тестовая сборка компилировалась на Mac; показ цветов на Windows, работа в HDR, на нескольких дисплеях, в полноэкранных приложениях и после сна не проверены.

Для сборки из этой папки с уже установленным .NET 8 SDK: `dotnet build Probe.csproj -c Release`. Тесты запускаются командой `dotnet run --project Tests/Tests.csproj -c Release` и не обращаются к реальному экрану.
