# Privacy

The current Monochrome app does not send network requests, collect analytics, record screen contents, access accounts or check for updates. It does not include a crash-reporting service.

It reads and changes macOS display-filter state. Those preferences are managed by the operating system. It has no separate application history database or user account.

GitHub itself hosts this repository, issues, CI and release downloads under its own terms. Data you choose to post in an issue is separate from the app. Keep reports free of personal information.

These statements describe the current source, not a claim that every future fork or binary with the same name behaves identically.
