# Системное переключение и границы подтверждения

Адаптер вызывает `UAGrayscaleSetEnabled`, `UAGrayscaleSynchronizeLegacyPref` и `_UniversalAccessDStart(8)`. Та же последовательность включения показана в опубликованной реализации displayutil.[7]

Это недокументированные символы, а не обещание стабильного публичного API Apple. Библиотеки и символы разрешаются через `dlopen`/`dlsym`; отсутствие символов приводит к ошибке, не к принудительному перезапуску служб.

В исследованном Bridge.h отдельно отмечено, что legacy CoreGraphics grayscale — не тот же фильтр, который использует современная система, и он не сохраняется через сон.[6]

Именно поэтому первая попытка использовать `CGDisplayUsesForceToGray` как независимый критерий провалилась: на испытанной системе современная настройка уже была `enabled=true/type=1`, а legacy getter возвращал false. Исторический провал сохранён в рабочей папке, не превращён в успешный результат. Итоговый native-тест проверяет современное состояние MediaAccessibility и явно не объявляет это наблюдением физического дисплея.

## Локальная приёмка

Проверено на macOS 15.6 / arm64 / Swift 6.1.2. Universal binary содержит x86_64, но Intel не запускался. AppKit-контролы проверены программно, настоящая кнопка обычного .app — через AXPress. Это разные уровни проверки, не физические клики мышью.

Нет собственного фонового сервиса, сети или автообновления. В 0.3.0 таймер на 25 минут работает только пока приложение запущено. Автозапуск после входа включается пользователем через меню и использует `SMAppService.mainApp`. При запуске и выходе приложение не меняет системный цветовой фильтр; таймер при выходе отменяется.

В локальной пользовательской проверке подтверждена работа основной функции на Mac. Это пользовательское подтверждение, не независимое наблюдение агента. Пользователь также подтвердил правый клик и появление значка после повторного входа с включённым автозапуском. Несколько дисплеев, сон/пробуждение, сценарий после отключения автозапуска, полный 25-минутный цикл на экране и нотариализованная раздача отдельно не подтверждены.
